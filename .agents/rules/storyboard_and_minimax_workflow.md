# 分鏡圖與 MiniMax H3 工作流提詞生成規範 (Storyboard & MiniMax H3 SOP)

當使用者指示「**幫我產出分鏡圖及 MiniMax 用的提詞**」或相關視訊分鏡任務時，**必須嚴格遵循本 SOP 標準化三段式結構產出**。

---

## 一、核心規則與規範

### 1. 🖼️ 分鏡首幀圖生成規範 (Storyboard Image Spec)
- **畫幅與風格**：預設 `9:16` 直式構圖 (`--ar 9:16`)，電影級熱血運動動漫風格 (Cinematic sports anime aesthetic)。
- **角色錨點一致性**：必須嚴格套用 [`characters.md`](file:///c:/Users/mice/.gemini/antigravity-ide/scratch/short-video-skills/projects/basketball-starter-21/characters.md) 中的固定外觀（例如陸子軒 #21 黑金紅邊球衣、黑色加壓褲、左手黑護腕）。
- **輸出內容**：提供可用於 Midjourney / SD 的英文 Prompt，包含景別、動態線條與高反差光影。

### 2. 🔌 ComfyUI 節點連接引導規範 (Node Connection Guide)
每次產出提詞時，**必須在提詞最上方明確標註圖片連接指引**：
- **Node 137 (`<Picture 1>`)** ➔ 當前鏡頭的分鏡圖 / 首幀構圖圖（鎖定運鏡與動作姿態）
- **Node 139 (`<Picture 2>`)** ➔ 主要角色視覺錨點圖（如陸子軒 #21 或高振峰教練，鎖定面部長相與球衣）
- **Node 147 (`<Picture 3>`)** ➔ 次要角色 / 對手防守者圖（如陳浩天 #4 或雷震 #0，若無則標註留空）

### 3. 🎬 MiniMax H3 專用提詞規範（方案一標準 · 直貼 Node 138）
提詞內容必須為**雙段完整結構（完整畫面描述 + 完整聲音指令）**：
- **【畫面段落】**：純中文撰寫，嚴禁中英混雜。開頭明確指定 `參考 <Picture 1> 的構圖與動作，<Picture 2> 的 [角色與特徵] 進行 [具體動作]...`
- **【聲音段落】**：台詞嚴格限制在 **4～8 個字** 的短爆發句（防止 4～5 秒內咬字被壓扁成外星語/模擬市民語）。
  固定語法：`聲音：一名[角色/性別]用中文[情緒]大喊："[4~8字短台詞]" 伴隨[具體物理撞擊/球鞋摩擦音效]與[球館氛圍音]。`
- **【參數安全備忘】**：
  - Node 132 (`Float Duration`)：設定為 **4 或 5 秒**（避免顯存 OOM 或畫面拖垮）。
  - Node 146 (`Enable Lightning LoRA`)：設為 **False**（跑標準 20 步採樣，調度器使用 beta 或 normal，確保音訊不破音金屬化）。
